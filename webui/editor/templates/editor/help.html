Справка

Рация

  • Прочитать — чтение кодплага с прогрессом и ETA, автоматический backup codeplug_backup_*.g77. Чтение ~15 с, можно отменить.
  • Записать — запись с подтверждением словом WRITE и backup codeplug_before_write_*.g77. Прервать запись нельзя.
  • Проверить — читает рацию обратно и сравнивает с буфером.

Каналы

  • Клик по имени или иконка карандаша — редактировать; + Канал — новый.
  • Иконка копирования — дублировать в первый свободный слот, крестик — удалить (слот, enable-бит и все зоны).
  • «Отменить / Вернуть» — undo/redo последних 30 правок.
  • Поиск ищет по имени, частоте, зоне, режиму, CC и контакту.

Зоны

  • Состав — клик по числу каналов. Переименование — в строке зоны, «Сохранить».
  • Удаление сдвигает ID последующих зон; каналы остаются в кодплаге.

Файлы

  • CSV экспорт — скачивание файла channels_*.csv (разделитель «;»), CSV импорт — загрузка с предпросмотром и ошибками по номерам строк.
  • Backup — копия текущего буфера на диск рядом с запуском.

Форматы

  • Частоты — МГц, можно с запятой: 145,500.
  • Тоны — Гц: 88.5; пусто = тона нет.
  • Имя канала — до 16 ASCII-символов.
  • Нумерация каналов — как на рации, с 1.

Важно

  • Не отключайте рацию и кабель во время записи.
  • Одновременно с WEB UI не запускайте TUI: порт последовательный.
  • Диагностика — в md9600_debug.log, события — в журнале.
